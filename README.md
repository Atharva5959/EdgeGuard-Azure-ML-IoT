Project Overview:

EdgeGuard is an Industrial IoT predictive maintenance
application that uses Machine Learning to monitor
machine sensor readings and predict potential failures.
Objective

To develop a real-time ML application that simulates
industrial sensor data, predicts machine failures and
displays results through a monitoring dashboard.

Technologies Used
- Python
- Scikit-learn
- Random Forest Classifier
- Pandas
- NumPy
- Streamlit
- Joblib
- Matplotlib
Project Features
- Synthetic industrial sensor dataset generation
- Machine Learning model training
- Real-time sensor data simulation
- Machine failure prediction
- Prediction history storage
- Interactive Streamlit dashboard
